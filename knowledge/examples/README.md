# knowledge/examples/ — comparative analyses, candidates, worked cases

Layer 1 writes here:

1. **Comparative reports** (master §34) — cross-paper analyses of specific subsets (e.g., "all 2024 generative-model best papers") along the nine §34 dimensions, outputting Common / Strong / Exceptional / Anti-Pattern / Domain-Specific patterns.
2. **Candidate patterns** — single-paper observations that may become `P00X` entries once a second paper exhibits them.
3. **Worked examples** — fully annotated Paper DNA files, diagnosis boxes, or attack matrices used to calibrate the layers.

These files are reference material for Layers 2–3, not checklists. Extract reasoning patterns, never sentences (§34).
